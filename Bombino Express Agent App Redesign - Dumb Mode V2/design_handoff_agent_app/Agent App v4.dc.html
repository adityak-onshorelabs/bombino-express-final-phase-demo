Room to breathe

The cramping came from forcing every screen to fit inside one viewport. These screens scroll, like any phone app, and the recovered space goes into padding, line height and touch targets. Type is bigger, one card fills the width, and there is a clear gap between one thing and the next.

Air

20px screen margins, 22px between sections, 16px inside cards. Fact rows are 60px tall instead of 40.

Bigger

Names 22px, addresses 17px, time and weight 20px, buttons 60px tall with 18px labels.

One thing at a time

New jobs lead the first screen, then the job in hand. The rest is below the fold, reached by scrolling.
