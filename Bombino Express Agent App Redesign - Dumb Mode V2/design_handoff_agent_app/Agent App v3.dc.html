Plain font, labelled facts, new jobs on the home screen

Font

One plain system sans everywhere — whatever the phone already uses. The condensed and monospace faces are gone. Numbers are tabular so amounts line up.

Every fact is labelled

Address, time and weight each get an icon and their own row in a boxed block. Time is 17px, not 11px. Nothing is a bare run of words any more.

New jobs on Today

A side-scrolling row of free jobs sits under the job in hand, with back and next buttons. The New tab still holds the full list.
